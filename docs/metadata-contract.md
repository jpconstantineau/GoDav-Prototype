# Metadata and conditional request contract (#7)

Public test seams: authenticated real HTTPS with temporary real SQLite, actual CLI process reopen, and in-process HTTPS for race coverage. These are approved seams; no private-table assertions substitute for public behavior.

DAV:creationdate is protected live UTC seconds (RFC3339) from immutable node creation. Four exact case-sensitive expanded names in urn:schemas-microsoft-com: are opaque strings: Win32CreationTime, Win32LastModifiedTime, Win32LastAccessTime, Win32FileAttributes. Prefix spelling is immaterial. Absent values are absent; these values do not change server timestamps or permissions. Unknown reads are 404, unknown patches 403.

PROPPATCH limits: 65536 body bytes, 32 XML nesting levels, 256 elements, 64 property operations, 4096 UTF-8 decoded bytes per stored value, 16384 aggregate decoded bytes per request and per node, 1048576 response bytes. Namespace/local names are at most 1024/255 UTF-8 bytes. Limit violations are 413. XML must be one complete DAV:propertyupdate with nonempty set/remove prop instructions, no DTD, trailing document/material or processing instruction except an initial XML declaration. Values are decoded XML text only; child elements/ordinary attributes on supported values are invalid (409). Empty/malformed structural XML is 400. Unexpected wrapper extension elements are ignored with their entire subtree and wrapper attributes are ignored (RFC4918 section 17), never interpreted as hidden patch instructions. Parse the full request before entering the operation gate. Never echo property values in patch status bodies or logs.

Ordered operations commit atomically. Protected live properties return 403 and DAV:cannot-modify-protected-property, invalid supported values 409, other operations 424 on failure. No successful status accompanies a failed atomic patch. Storage publication failure returns outer 207 with a 500 property status and dependent 424 statuses, never false 200. Both bounded response outcomes are encoded before publication. Valid operations return outer 207; absent resource 404 and false request preconditions 412. Compare final metadata state with initial state: effective change rotates a persistent random strong file ETag in the same transaction; no-op/remove-absent/failed patches do not. Content and server-owned last modification time remain unchanged. Collections have no file ETag or GET representation.

HTTP preconditions: strong If-Match, weak If-None-Match, lists across field lines, standalone wildcard. Entity-tag parsing validates the entire field including opaque commas, bounded to 8192 combined bytes and 128 tags; malformed syntax 400, bound excess 431. Invalid dates are ignored. If-Match suppresses If-Unmodified-Since; If-None-Match suppresses GET/HEAD If-Modified-Since. Write If-Modified-Since and If-Range are ignored. GET/HEAD false If-Match/unmodified conditions return 412; matching If-None-Match/not-modified dates return 304. Existing collection wildcard conditions use resource existence; explicit tags cannot match a collection. Normal auth/path/method/resource errors precede condition evaluation. PUT and applicable MKCOL expectations are evaluated inside the publication transaction after staging, and PROPPATCH inside its atomic transaction. Unsupported DAV If/Lock-Token on writes return 501 pending #8. ServeContent remains responsible for range responses; absent or empty If-Range preserves ordinary range handling; otherwise only a complete exact strong If-Range token permits range use (date/weak/malformed values yield full 200).

Schema v4 adds bounded metadata keyed by stable node ID, preserving v3 file bytes/tags and all account state. Existing read-only opens never migrate; explicit server preparation migrates. Malformed/unsupported schemas fail closed. No Windows Explorer/SCM or Linux native execution is implied by automated checks.

References: RFC 4918 sections 9.2, 14.23, 14.26 and 17; RFC 9110 section 13; Microsoft MS-WDVME section 3.1.5.6; pinned golang.org/x/net v0.62.0 webdav/prop.go and Go 1.27.4 net/http/fs.go.
